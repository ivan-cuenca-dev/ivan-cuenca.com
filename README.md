# Astro Web

This is a portfolio website for my work.

## Tech Stack

- [Astro](https://astro.build) - Static site generator
- Vanilla CSS - Styling
- Vanilla JS - Interactive features
- Markdown - Content

## Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/     # Reusable UI components
├── content/        # Content collections (posts, projects, snippets)
├── layouts/        # Page layouts
├── pages/          # Route pages
├── styles/         # Global CSS
└── config.ts       # Site configuration

public/
└── images/         # Static images
```
